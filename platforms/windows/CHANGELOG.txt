v1.9.0 Windows
--------------

- validates Windows install/update/portable migration/uninstall, schedule ownership, private-data preservation, cross-platform Manager compilation, accessibility, JavaScript, and release artifacts in CI
- remains unsigned for this release; users should verify TautWeekly-Setup.exe against SHA256SUMS.txt before accepting a SmartScreen warning
