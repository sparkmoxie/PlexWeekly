All packages · Private configuration · Native-email safe

A deliberate fallback, never a redirect

Manager shows an accessible assignment card only for active native-email-blank users. TautWeekly keeps native email authoritative, applies the existing ID and effective-address exclusions, and uses the fallback only for production paths that already target the selected user.

  • Assignments are keyed by stable numeric Tautulli user ID and may share one inbox
  • Clearing an assignment returns that profile to missing-email status without changing history
  • Failed discovery retains the last sanitized choices and private assignments
  • TestEmail remains isolated from production addresses
  • Recipient coverage changes regenerate previews and refresh enabled cache coverage
  • Sanitized caches, results, and diagnostics never contain the map or fallback addresses

Installation tracks

One renderer, five operating models

Each Quickstart is standalone and keeps its platform's setup, scheduling, preview, and recovery workflow intact. Linux Docker servers use the NAS/Docker track—dedicated NAS hardware is not required—while the native Linux track is Docker-free. Both are headless and use the same Manager and newsletter behavior. Manager Settings > Updates is the shared status source, while installation remains owned by the verified Windows updater or the documented host-native tool.

Upstream readiness

Refresh metadata before acceptance

Use the same upstream sequence on every platform.

01

Confirm the movie source

In every included Plex Movie library, confirm Edit → Advanced → Ratings Source.

02

Refresh Plex

Run Manage Library → Refresh All Metadata for every included movie/TV library and wait.

03

Refresh Tautulli

Open each same Library → Media Info tab and select Refresh media info. Repeat per library and wait.

Plex warns that full-library refreshes can take significant time and can update metadata or artwork. Do this after first setup, after a Plex agent/source change, or after a ratings/artwork recovery update when data may be stale. Routine TautWeekly updates do not require it when current output is correct. Tautulli's step updates its table; it does not replace the Plex refresh.

Safety sequence

Production is the last step

The same operating discipline applies across all platforms.

01

Configure

Enter private Tautulli, SMTP, branding, and schedule values in Manager Config. Restore or individually confirm-delete private configuration backups there as needed.

02

Prepare metadata

Complete the Plex and per-library Tautulli refresh sequence above.

03

Verify

Check runtime, storage, network, API, and mail settings.

04

Preview

Generate six deterministic HTML states without sending mail.

05

Validate real MIME and client rendering with a controlled recipient.

06

Schedule

Enable automatic delivery only after roster and exclusion review.

Credential boundary

Runtime data is never source data.

Live configuration contains an SMTP credential and Tautulli API key, and may contain a Plex token. State, logs, previews, and backups may reveal recipients and server activity. Weekly Binge Champion cards share only anonymous watch time, total plays, nonzero unique movie/TV-show counts, and the cumulative qualifying episode count when greater than one; the champion's identity and titles remain private.

Native Windows and Linux can optionally publish their password-protected, loopback Manager through Tailscale Funnel. The login page becomes publicly reachable over HTTPS, and remote viewers need no Tailscale or VPN client. Container/NAS, macOS Docker, FreeBSD/Podman, QNAP, Synology, and Unraid use an isolated userspace Funnel adapter with exact fixed-target cleanup. Every remote session has full administration, so Manager authentication and local recovery remain independent boundaries.
