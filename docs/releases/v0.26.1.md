# TautWeekly for Plex v0.26.1

Released: 2026-09-09

## Exclude the anonymous Local identity

Tautulli creates **Local**, user ID `0`, for unidentified or unauthenticated
activity. It is not a managed Plex profile. Its presence alone does not mean
anonymous viewing has occurred.

This hotfix removes the reserved identity from Manager discovery, retained
user choices, delivery-address prompts and counts, terminal selectors,
personalized previews and test messages, welcome tracking, production delivery,
and deleted-item cache recipient coverage. A saved fallback address cannot
make it eligible. The rule matches the reserved numeric ID, not the display
name, so real users named Local remain supported.

No manual exclusion or configuration cleanup is required. Existing private
assignments for other users remain intact, and Tautulli's anonymous playback
history is not deleted.

## Verify lookup identity

Tautulli can return Local as a fallback when an individual user cannot be
resolved. TautWeekly now requires the returned ID to match the requested user.
A mismatched response falls back only to an exact matching bulk-roster entry;
if no unique match exists, the lookup fails closed before that user's
personalized newsletter is generated or sent.

## Validation boundary

Regression coverage checks numeric and string zero IDs, real nonzero users
named Local, retained discovery, legacy fallback assignments, requested-user
identity mismatches, recipient policy, welcome state, and cache coverage.
The release retains the cross-platform renderer, privacy, package, Windows
installer, and multi-architecture container gates. Live SMTP/provider
acceptance remains an operator-controlled TestEmail check.
